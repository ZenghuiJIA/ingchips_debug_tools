# Release v1.1.0 (2026-09-23)

AI-HIL 嵌入式硬件在环（Hardware-in-the-Loop）测试与调试系统正式发布 **v1.1.0** 版本！

本版本带来了多项重量级硬件级调试与观测功能，涵盖基于 JSON 配置的 Rust 后端实时波形协议解析引擎、ARM Cortex-M SVD 外设寄存器可视化检测、CMSIS-Pack 算法自动烧录、J-Scope 变量自动捕获与 SWD 物理频率反推保护，以及 Keil MAP 固件资源占用全景分析。

---

## 🌟 核心新特性与更新概要 (What's New)

### 1. ⚡ 基于 JSON 配置的 Rust 后端实时波形协议解析引擎
- **Rust 后端高性能流式解码**：
  - 新增 `protocol_engine.rs`，在底层后台读取线程中以滑动窗口流式对齐帧头、定长截取、帧尾匹配与校验和计算，彻底避免前端卡死与分包/粘包错位。
  - 支持多通道字段配置：支持 `float32`, `float64`, `int32`, `uint32`, `int16`, `uint16`, `int8`, `uint8`，大小端解码，以及 `scale` 倍率缩放与 `bias` 偏置偏移。
  - 毫秒级直接通过 `waveform-points` 事件将多通道数据推送到前端渲染，CPU 占用极低。
- **自定义 JSON 协议交互界面**：
  - 示波器协议配置弹窗中支持实时编写下发自定义 JSON 协议，即改即生效。
  - 内置丰富预设模板：
    - **自定义二进制帧 (0xAA55 六轴 IMU 数据包)**
    - **VOFA+ JustFloat 原生浮点数组**
    - **FireWater 逗号分隔与键值对文本流**

### 2. 🎯 J-Scope 变量自动捕获与 SWD 频率反推保护
- **顶部标签更名**：将原 “J-Scope 监视” 规范命名为 **“变量自动捕获”**。
- **AXF / ELF 符号解析支持文件浏览**：新增系统级原生文件选择对话框，支持一键浏览选择固件符号文件。
- **多核心调试兼容**：适配 Cortex-M4, M3, M0/M0+, M7 通用调试目标，支持 uint, int, float 等多种数据类型实时观测。
- **SWD 物理频率反推保护**：
  - 支持高达 1MHz (1µs) 采样周期配置。
  - 结合当前 SWD 探针时钟频率与监视变量数量，自动计算硬件物理总线通信耗时并反推硬件采样极限。低频率下自动限制过高采样率并给出预警提示，防止总线拥塞或通信超时。

### 3. 🔍 ARM Cortex-M SVD 外设寄存器全景可视化
- **SVD 树状寄存器查看与实时读写**：
  - 支持在线解析芯片 SVD（System View Description）模型，按外设（Peripheral）、寄存器（Register）、位域（Field）三级树状展示。
  - 支持单寄存器读取、整组外设寄存器批量极速拉取，以及位域直接解析并以 HEX/BIN 双重展示。
  - 具备全兼容鲁棒性解析器，兼容多种 Keil DFP CMSIS-Pack 中嵌套或格式不一的 SVD 文件（包括 GigaDevice GD32F4xx 等第三方厂商包）。

### 4. 💾 CMSIS-Pack 算法导入与固件烧录
- **Pack 下载算法自适应**：
  - SWD 烧录界面支持导入第三方厂商 CMSIS-Pack，自动解包并提取内置 Flash 烧录算法与设备参数。
  - 针对非标芯片无需手动配置底层烧录驱动，实现即插即烧。

### 5. 📊 Keil MAP 固件资源占用全景分析
- **ROM / RAM 空间分布透视**：
  - 支持导入 Keil MDK 生成的 `.map` 链接映射文件。
  - 自动解析 Code, RO-Data, RW-Data, ZI-Data 分布，可视化统计 Flash 与 SRAM 占用百分比。
  - 支持按函数、全局变量以及目标模块（.o / .lib）进行体积排序与搜索过滤，助力嵌入式代码瘦身与内存优化。

### 6. 🚀 高速 SWD 通道与 RTT 自动扫描
- 支持根据 Pack 目标芯片默认 RAM 地址范围，或根据 Cortex-M3/M4/M0 默认核心内存空间，自动扫描定位 SEGGER RTT 控制块（`_SEGGER_RTT`），实现无侵入零串口引脚占用的高速日志通信。
