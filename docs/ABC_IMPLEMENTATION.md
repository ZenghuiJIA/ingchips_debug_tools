# ABC 实施记录

本轮依次交付会话与记录（A）、共用协议和命令事务（B）、历史分析与插件（C）。保留现有页面，所有新增行为从现有终端、协议面板、HIL 和波形入口使用。

- A：后台会话日志、完整 RX/TX、分卷和故障状态；日志搜索/过滤/书签/历史；独立触发匹配；设备身份和可选重连；发送快照与连接代次检查。
- B：无 UI 依赖的 Rust 协议库及 headless 适配器；会话隔离、校验和恢复；帧检查与命令应答；生成和执行同一 HIL 配置。
- C：采集与显示暂停分离、时间戳 CSV、区间统计、会话回放与事件定位、运行比较；可信本地插件的超时/崩溃隔离。

记录携带 schema_version、session_id、seq、direction、elapsed_ms、wall_time_ms 和原始数据。连接更换生成新 session_id；旧动作必须拒绝。协议配置和命令在开始时固定。回放不获取设备句柄，插件只接收数据，不通过宿主直接操作设备。

验证调用生产实现：拆粘包、错误帧恢复、数值边界、并行会话、快速与迟到应答、断线取消、原始记录完整性、回放倍速一致性、统计和插件故障。另执行前后端构建、冻结 daemon、headless 适配器与发布 ZIP 校验。未经实机验证的结果单独说明。
