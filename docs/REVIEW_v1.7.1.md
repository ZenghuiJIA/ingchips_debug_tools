# v1.7.1 助手审查与回归记录

## 本次处理范围

在已有大量未提交的 Rust 迁移与功能扩展之上增量修复，未回滚旧工作，未升级依赖。审查以真实调用链为主：串口接收与展示、HIL 编辑/校验/提交/执行/报告、桌面资源交接、Python 探针桥接、ING 与 PyOCD 烧录边界。既有网络、Modbus、波形 DSP、协议、SVD、插桩、仪器和故障分析通过对应生产逻辑回归检查；不据此宣称已经穷尽整个应用的所有缺陷。

## 确认并修复的问题

| 问题 | 根因与处理 |
| --- | --- |
| 勾选自动滚动后无法翻历史 | 采集空轮询每 150 ms 无条件滚底；仅非空新消息刷新跟随，历史重绘不跟随 |
| 字体、字号和颜色不能调整 | 增加经过边界校验的外观偏好与持久化，文本/HEX/VT100 实际展示均接入 |
| HEX 跨块显示连在一起 | Worker 去掉尾部字节分隔后日志直接拼接；保留分隔，增加生产 Worker 回归 |
| 脚本导入丢参数和嵌套步骤 | 两套前端白名单重建脚本且注入动作默认值；改为无损编辑、后端统一验证 |
| 双击启动、旧响应污染新任务 | 提交前锁定、不可变快照、任务代次校验，后端先原子预约再交接串口 |
| 拒绝启动后界面永久未知 | 仅明确的 `HIL_NOT_STARTED` 契约允许解锁；真正传输结果未知继续保护，禁止盲目重试硬件 |
| 最后一批日志丢失、提前显示结束 | 分页有界读取，收到最终报告后才解除运行保护；不以固定等待代替完成条件 |
| 中止或重试后统计误导 | 报告区分计划/执行/未执行/尝试/失败/取消，保留失败，旧统计缺失显示未知 |
| 畸形内存返回值变成 0 | 边界要求每字节为 0–255 整数，缺失和错误不再参与断言 |
| 逐字节发送不及时取消 | 每字节及等待间隙检查任务截止/取消，步骤截止受整轮截止约束 |
| 服务退出后 worker 继续执行 | 独立原生监督器、启动门闩、活动任务身份和受控回收；首次最终报告明确为 INTERRUPTED |
| Python 桥接接受错误信封 | 校验 JSON-RPC 版本、ID、结果/错误互斥与结果结构 |
| 离线符号解析仍绕 Python | 复用 Rust ELF 解析；拒绝未定义、重复或超出 32-bit 的地址并限制读取大小 |
| SWD 扇区烧录可能丢失邻接数据 | 恢复保留未覆盖字节选项，准备阶段暂停而非隐式复位，取消保护覆盖 programmer 构造阶段 |
| ING 自动复位猜测接线 | 未验证接线不发 RTS/DTR 脉冲，不在握手失败后补发复位；前端禁用不支持的选项并说明原因 |

## 构建一致性

某些精确文件编辑会保留源文件时间戳，导致 Cargo 增量缓存未察觉变化。本次同时清理了本仓库 `hil-runtime` 与 `ai-hil-debugger` 的开发及 release 包缓存，再重新测试/构建；不清理历史发布目录。通过新增测试名与二进制内最终功能标记核对真实重新编译，而非仅凭构建命令 exit 0。

旧工作区兼容 daemon 仍被其他调试进程占用时，不强制结束该进程；新产物单独交付。源码、构建目录、新发布包和当前运行进程不是同一状态。

## 仍需明确的能力边界

1. **未实板验收**：未执行物理烧录、复位、内存写入、射频、热插拔或长时间高吞吐压力测试。Mock 和浏览器预览结果不计作硬件通过。
2. **ING20 SWD 暂不可用**：既有代码记录内嵌算法风险，而 PATH CLI 绕过不能保持 Pack、独占、取消和最终状态契约，因此前后端均明确拒绝，等待经过验证的适配。ING 串口路径独立保留。
3. **无接线配置的自动 RTS/DTR 暂不可用**：桌面 ING 窗口使用手动 ISP；HIL 的显式复位步骤仍可使用已核对配置。
4. **ING 串口不具备扇区读回合并保证**：已有 ING916 路径会按扇区擦除；本次 `keep_unwritten` 修复针对 PyOCD 选项契约，不能泛化为所有后端都保留邻接字节。
5. **Python 未完全删除**：PyOCD/J-Link、SVD/Pack 兼容和深度诊断等生态依赖保留；主机串口、HIL 执行和适合的离线处理继续使用 Rust。
6. **提交结果未知且没有 run_id**：界面不会自动解锁重试；仍需核查后台任务。没有用模拟成功或盲重试掩盖这一恢复边界。
7. **性能仍有待测项**：Vite 提示主 bundle 较大；高吞吐丢失率、内存峰值和长期稳定性仍需专项测试。本批不做全仓布局或架构重写。
