# v1.3.8 多语言国际化支持（简体中文 / 繁體中文 / English）与构建前词典门禁

## 国际化与多语言体验

- 新增 **繁體中文（`zh-TW`）** 完整词典（1210 项词条与 `zh` / `en` 保持 100% 同步），并在设置弹窗提供 **简体中文 / 繁體中文 / English** 三栏一键切换。
- 支持首次启动按系统语言（`navigator.language`）自动匹配界面语言，并在切换时同步更新 `document.documentElement.lang`。
- 清理主框架导航分类、快捷索引浮层（`Ctrl+K`）、异常兜底卡片与状态栏硬编码文案，全部接入 `t(...)` 国际化渲染。

## 工程化门禁与工具

- 新增零依赖构建前检查脚本 `scripts/check_i18n.mjs` 并集成至 `pnpm build`：在编译前自动拦截重复 key、语种缺漏 key、占位符不一致与未定义 `t('key')` 引用，并补齐此前遗漏的 28 处组件词条。
- 新增 `scripts/sync_i18n_tw.py`，支持基于 OpenCC（`s2twp`）从 `zh` 一键同步生成 `zh-TW`。
