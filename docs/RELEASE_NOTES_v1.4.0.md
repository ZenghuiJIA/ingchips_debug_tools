# v1.4.0 HIL 后台执行

新增独立工作进程执行的 HIL runner，桌面 Sequencer、命令行和 MCP 共用执行逻辑。保留 UI 步骤编辑、参数调整、日志、报告与原有手动硬件页面，增加 HIL 自测模板、选中步骤运行和 JSON 编辑。

串口持续记录到磁盘，等待使用独立游标，支持拆包和同批 BOOT/DONE；HILv1 观察检查启动次数、心跳、结果一致性和完成状态。失败保存串口尾部并尝试寄存器/RAM 取证，报告输出 JSON、JUnit 和 HTML。后台取消、超时与异常中断分别记录，重试失败不会被后续成功隐藏。

脚本支持 JSON/YAML、工位默认值、参数覆盖、块循环、块读取及 ELF 符号读取，提供事件回放和示例。探针按整轮独占，服务短请求查询状态；关闭服务会取消工作进程，CLI 可用于独立长测。

本版自动烧录仅支持 PyOCD HEX/ELF/AXF，自动复位仅支持 SWD；ING 和板级引脚复位继续使用原有手动页面。多板调度、电源控制、常驻系统服务、通用子流程库、步骤间暂停和中途恢复尚未实现。详见 docs/HIL_RUNNER.md。

验证采用软件回归、冻结 EXE 验证及桌面构建。软件回归包括 HIL 17 项、daemon 10 项、前端生产逻辑 10 项和 Rust 11 项；冻结 EXE 检查 CLI、YAML、回放、MCP 生命周期和报告。未执行真实板卡烧录、时钟压测和 HardFault 注入；这些能力需按实际工位验收。浏览器连接不可用/超时，界面视觉验收未完成。
