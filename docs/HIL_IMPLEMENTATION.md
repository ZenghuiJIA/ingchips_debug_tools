# HIL 执行改造

执行状态由独立 Python 工作进程持有，UI/MCP 仅提交、查询和取消。运行参数在启动时固定；日志、步骤尝试和最终报告写入独立运行目录。串口在触发固件运行前打开，匹配只移动消费者游标。探针锁覆盖整轮测试，单次 PyOCD 操作允许同线程重入。

保留现有页面与参数编辑，自动流程和选中步骤均使用后端。ING 手动烧录保留，第一版自动执行仅支持 PyOCD；不支持的脚本动作在启动前拒绝。工作进程取消是协作式的，硬件阻塞超过截止时间后由监督器终止并记录结果未知，不继续下一步。失败先取证，默认不复位恢复。

验证包括生产解析/执行器故障注入、冻结 EXE 的 CLI/MCP、前端契约、Rust 测试、桌面构建与发布包检查。没有指定开发板，不执行实机烧录。
