# v1.5.0 串口、协议和回放分析

A：串口/RTT 后台 RX/TX 记录、连接身份、有界游标读取、日志搜索/过滤/高亮/书签、发送历史、USB 唯一身份回连。触发器使用独立匹配窗口，格式切换不影响匹配；发送循环使用配置快照和会话校验。

B：新增 hil-debug-core Rust 协议库和 hil-protocol.exe，桌面、Python HIL 和离线重解析共用。支持字段/位域/枚举、长度字段、校验范围、帧错误列表、字段字节定位、请求应答和导出 HIL 步骤。协议请求先准备接收窗口，禁止重复应答身份和超时后盲目重发。

C：增加离线事件查看、协议重解析、时间区间统计、曲线定位原始事件、倍速回放和两轮统计比较。波形暂停保留采集，CSV 保存真实主机时间和通道。提供可信本地 Python 插件的进程隔离、输出限制和超时处理。

本版保留原有 UI 与手动页面。网络会话和原有控件/波形解析仍有兼容路径；新能力的限制、文件格式和使用方法见 docs/ABC_DEBUGGING.md。未做真实板卡联调和 USB 插拔验证；界面自动化连接超时，视觉验收未完成。
