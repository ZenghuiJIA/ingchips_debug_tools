# v1.7.1 — 自动化可靠性与串口交互修复

## 串口

- 新增可持久化的字体、字号（8–32 px）、文字/RX、TX、提示、错误与背景颜色设置，以及恢复默认外观。文本、HEX 与 VT100 共用设置，VT100 保留设备 ANSI 颜色。
- 自动滚动仅在新消息到达时跟随；空轮询不再每 150 ms 强制拉回底部，用户可以在空闲时向上阅读历史。切换显示格式重绘历史不触发跟随。
- 修复无 Worker 时 HEX 模式错误显示文本，以及 Worker 连续 HEX 数据块缺少字节分隔符的问题。

## HIL 编辑与执行

- 导入及编辑不再丢失参数定义、嵌套循环或未知字段；未知字段交由 Rust 预检明确拒绝。保留旧 schema 的数字解释，不擅自升级脚本语义。
- 启动使用不可变快照，提交期间防重复启动；轮询与具体任务代次绑定，避免旧响应覆盖新任务。错误、停止中和结果未知不会当成完成。
- Rust 原子预约先于桌面串口交接，重复任务不会先关闭正在使用的终端。
- 修复内存字节返回值缺失/畸形被当成 0 导致断言误通过；增加范围、对齐和参数类型校验。
- 逐字节发送可响应取消与截止时间；步骤截止时间不能越过整轮截止时间。
- 报告新增计划、执行、未执行、重试尝试和取消等独立统计。失败后重试通过仍保留失败；纯延时成功不标为硬件验证通过。
- 符号到地址解析复用 Rust ELF 实现，不再为该离线步骤请求 Python；只接受唯一、已定义、32-bit 地址范围内的符号，限制读取资源。

## 烧录安全边界

- 通用 PyOCD 扇区烧录保留未覆盖字节；准备阶段暂停而不隐式复位。保留无 stdout 进度回调，避免污染 JSON-RPC。
- HIL ING 下载不再猜测 RTS/DTR 接线或在握手失败后自动补复位。没有已核对接线配置的路径使用手动进入 ISP。
- ING20/ING2000 的旧 PATH 外部 PyOCD 回退不能保持 Pack、取消、设备租约及烧录后状态契约；在有经过验证的兼容实现前明确拒绝该 SWD 烧录路径，而不是冒充成功。ING 串口下载为独立路径。

## 版本与交付

桌面、前端、Rust runtime 与 Python MCP 版本统一为 1.7.1。保留原有多模块 Rust 迁移与 Python 探针兼容实现，不对整个项目重写。新发布包必须来自本次前后端和 worker 构建，不复用历史 EXE 冒充更新。

## 验证边界

生产逻辑回归和无硬件进程测试用于验证协议、配置、状态与报告。浏览器预览验证用于布局和交互，不代表物理设备验收。未执行真实板卡烧录、复位、内存写入、射频或热插拔验证；芯片 Pack、接线和长时吞吐仍需在明确目标工位上验收。具体构建及测试结果以本次交付记录为准。
