# v1.5.0 串口、协议与历史分析

本版沿用原来的页面和手动调试入口，增加 A（会话/日志）、B（协议/命令事务）、C（历史分析/插件）。新协议核心位于 `src-tauri/debug-core`，桌面直接链接，Python HIL 调用同源的 `hil-protocol.exe`，发布时必须携带该文件。

## A：会话与记录

串口标签上可设置别名。具有 VID/PID/USB 序列号的设备可以启用断线自动回连；候选不唯一、无序列号、端口仍被其他程序占用时不接管。手动断开和交给 HIL 不触发自动回连。重连后的发送循环不会续跑，触发规则需要重新启用。

终端工具栏新增搜索、高亮、排除、正则过滤、书签、发送历史和后台 RX/TX 录制。书签保留当前页面内最多 200 条内容；发送历史最多 100 条，选择历史只填入编辑框。正则过滤作用于当前有界显示窗口，完整历史通过录制文件分析。规则匹配使用原始 RX 的流式文本解码，独立游标，不随 HEX 显示改变。延迟应答校验连接身份，最多 100 个待发送动作。

串口/RTT 后端为每个连接创建 session_id，保留约 2 MiB 原始事件环形窗口，最多 10000 个事件。UI 按游标读取；窗口覆盖会明确提示缺口。文本/HEX 切换从保留的原始事件重绘。日志显示最多约 1 MiB，单项最长 16K 字符，超长内容标记截断。网络终端保持原路径，暂不具备同等后台录制和会话代次能力。

录制目录位于 `%LOCALAPPDATA%/AI-HIL-Debugger/captures`。开始录制只包含开始后的数据；每卷约 16 MiB，每次录制最多 1 GiB，达到上限后明确报告不完整。写入使用有界后台队列，错误/队列溢出不会伪装完整成功。分卷目录附带事件偏移索引，后续分页从检查点继续。停止后写入 manifest.json，进程意外退出缺少 manifest 时读取器提示记录可能不完整。录制不依赖页面挂载；关闭串口会结束对应录制。

记录事件包含 schema_version=1、session_id、seq、port、direction、elapsed_ms、wall_time_ms、HEX data。elapsed_ms 为连接内单调时间；wall_time_ms 供显示。RX/TX 保留原始字节。HIL 记录保留原有 kind 字段并添加同类方向/身份信息；旧记录按兼容方式读取。

## B：协议工作台

终端打开原有协议面板，默认进入共用协议工作台，也可切回原有控件调试。字段表提供名称、偏移和类型编辑；完整 JSON 模板提供长度字段、位域、枚举和校验范围。默认只预览，发送须明确点击。原有控件调试保留，新增了严格 HEX/范围和会话校验；旧控件编码属于兼容路径，不承诺与新模板完全等价。

流程：编辑模板及发送值 → 预览编码 → 绑定接收解析 → 检查帧列表 → 发送并检查应答 → 导出 HIL 步骤。帧列表保留最近 500 帧，包括错误帧；点字段可高亮对应字节。模板导出为 JSON，HIL 步骤可在 Sequencer 中打开，复杂参数通过 JSON 编辑器调整。

模板 schema_version=1。支持固定长度、长度字段或非空帧尾，最大帧长 65536 字节；字段支持 uint8/16/32、int8/16/32、float32/64、bool、定长 bytes/string、大小端、scale/bias、无符号位域和枚举。字符串为 UTF-8，bytes 是 HEX。数值超出范围拒绝，不能自动截断。非位域字段不可重叠。

长度字段的 `size` 为 1/2/4 字节，帧总长度为读取值加 adjustment；字段字节序沿用协议 endian。校验支持 sum8、xor8、crc16_modbus、crc16_ccitt；offset/end 可为负数，表示相对帧末尾，计算区间为 `[start,end)`，默认 end=offset，不能包括校验字节。示例见 `examples/hil/protocol-aa55.json`，该协议只是示例，不代表任何实际板卡。

每个会话的解析状态独立。错误校验、非法长度和噪声输出错误帧并重新同步；无帧头协议只能按声明边界恢复。partial_timeout_ms 用录制/接收时间判断半帧超时。

命令事务在发送前建立游标，整个等待期间独占该会话的写操作。`expected` 为非空字段等值断言，建议包含序列号和命令码。同一连接/运行内不能重复使用相同“协议+expected”身份（最多 1024 个），避免迟到的重复应答被下一请求接受；序列号需要调用方递增，UI 提供示例 seq+1。没有可区分序列号的协议不能保证重复请求关联，因此需重新连接或由项目另行定义事务边界。超时后标记结果未知，重新连接/运行前不再发送事务；不自动重发。

HIL 新增 `protocol_request`，参数为 port_name、baud_rate、protocol（对象或相对文件路径）、values、expected，步骤 timeout_ms 控制时限。默认 CLI 验证会启动纯协议适配器验证模板，不连接设备。示例见 `examples/hil/protocol-request.hiltest.yaml`。

工作台的“停止当前请求”按会话和 request_id 取消，不能取消其他请求。取消后发送结果可能未知，需要重新连接再运行事务；它不会撤销设备已经收到的命令。

## C：历史分析

终端和波形页面均有“记录回放与分析”入口。可打开 JSONL 分卷文件、完整分卷目录和时间戳 CSV。预览限制为 20 万事件/约 64 MiB；原生重解析最多 32 MiB RX 数据、10 万帧。超限明确拒绝，可选择较小分卷。解析从完整加载段起点执行，播放定位只改变查看位置，不从任意半帧重新解析。

加载记录后可以查看事件时间线，使用协议模板重新解析成数值，Shift 拖动曲线选取区间，统计样本数、最小值、最大值、均值、总体标准差和峰峰值。统计使用加载范围内的原始样本，显示降采样保留区间极值。点击曲线点关联原始事件（来源仍在记录中时）。播放支持 0.5×/1×/10×，不改变录制时间和解析结果；回放没有设备操作接口。

波形页面暂停只冻结绘图，采集继续，实时内存仍保留最多约 50000 点/通道。长期数据使用后台录制。CSV 改为长表 `timestamp_ms,channel,value,session,source_seq`，保留非同步通道时间，不补零。旧 SampleIndex CSV 没有时间信息，不能推断真实时间，导入时会明确拒绝。模拟数据切换时清空当前波形，导出文件名标注 SIMULATED。

时间戳代表主机接收/观测时间，不等于 MCU 采样时间，同一个接收块中的多个样本可能具有相同时间。实时旧波形绘图仍以样本索引布局；精确的时间区间分析使用新分析窗口。比较第二次运行时导入另一份时间戳 CSV，指定两轮锚点后比较同一相对区间的通道均值/数量，不自动插值或补缺样。

可信本地 Python 插件在独立进程中运行，定义 `decode(payload)` 并返回 samples/annotations。输入与输出各最多 1 MiB，最多 10000 样本/1000 注释，超时 100–10000 ms；UI 默认 5 秒。插件路径和 SHA256 随结果返回。独立进程用于故障隔离，不是安全沙箱，Python 代码拥有当前用户权限，只应运行已审阅的本地代码。宿主不向插件提供设备句柄，输出仅用于离线分析，不作为硬件测试通过结果。示例见 `examples/hil/plugin_ascii.py`。

## 验证与已知边界

软件回归覆盖独立报文向量、拆粘包、长度/校验错误恢复、数据越界、会话隔离、即时应答、错误序列、重复身份、取消、日志分卷/上限、CSV/区间统计、降采样尖峰、回放隔离和插件错误/超时。冻结 EXE 和发布包另行验证。

合成编解码基线（开发构建、无硬件）：每批 1/16/128 帧分别约 5720/26169/34308 帧/秒，适配进程峰值约 3.9–4.4 MiB。该结果不是串口吞吐、长期稳定性或 UI 性能承诺。

真实 USB 插拔、高速长测、实际协议设备联调仍未上板验收。界面自动化工具连接审批超时，视觉检查未完成。网络会话、现有波形旧协议路径保留兼容，后续可继续迁移；新的协议工作台/HIL/离线重解析已共用同一原生协议实现。
