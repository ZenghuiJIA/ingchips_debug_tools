# v1.3.4 串口助手专项修复

## 串口与网络会话

- 修复 TCP Client、TCP Server、UDP 标签误走物理串口打开/关闭命令的问题。
- 网络标签正确区分监听和已连接状态，页面重建时恢复后端会话；隐藏不适用的串口波特率、端口和 DTR/RTS 控件。
- 串口/网络断开事件携带会话身份，旧 worker 不能污染或删除新会话。
- 修复复位期间关闭并重连后，DTR/RTS 脉冲可能作用到新会话的问题；复位、发送、协议事务和引脚控制增加互斥。
- RTT 重复连接、非法端口和连接/单次写入超时得到明确校验。

## 日志与交互

- capture 历史覆盖告警按会话只提示一次，避免轮询刷屏。
- 清屏和端口/session 切换同步清理旧书签和采集游标。
- Worker 串口数据使用 Transferable ArrayBuffer，降低高吞吐日志复制开销。
- 保留既有字体、字号、颜色设置，以及“只有新消息到达才自动滚到底部”的行为。

## 资源与烧录交接

- capture 缓存仅保留最近 8 个已关闭会话，活跃会话不因缓存逐出而失效。
- 烧录恢复失败不再误发“串口控制权已归还”的成功事件。
